# Kuroii Motion AI Desktop 应用规格 v2.0

## 1. 定位

Desktop 是 Suite 中控，不是“大号扩展”。

## 2. 功能

```text
Home
Copilot
Projects
Jobs
Workflows
Assets
Library

Provider Hub
Actions
Scripts
Expressions
Capability Registry
Extensions
Diagnostics
Account
License
Updates
Settings
```

## 3. 工作区

```text
General
After Effects
Premiere Pro
Cross-Host
```

General：Copy、Translate、Storyboard、Prompt、Glossary、Assets、Projects。  
AE：Compositions、Layers、Motion、Expression、Script、Analyze、Render。  
PR：Sequences、Clips、Subtitle、Edit、Audio、Analyze、Export。

## 4. 专业模式

```text
Trusted Actions

Parameters

Safety

History
```

## 5. UI

- 完整侧边栏
- 侧边栏展开/收起
- 收起只显示图标
- 图标 Hover/Focus Tooltip
- Light/Dark/Follow System
- 主题即时切换
- zh-CN/en-US 即时切换
- 预留 ja-JP/ko-KR
- Compact/Comfortable/Spacious
- 多栏专业工作区
- 高 DPI
- Kuroii Cat 分级使用

## 6. Extension Manager

检测 Adobe 版本、安装、更新、修复、卸载、开启 CEP Debug、兼容提示。

## 7. 发布

Windows 与 macOS，Intel 与 Apple Silicon；macOS 纳入签名和公证。
