## 冻结规则

- 不得删除 Copy、Translate、Storyboard、Motion、Expression、Script、Subtitle、Edit、Audio、Assets、Project 等已确定专业功能。
- Copilot 是统一入口，不替代专业模块。
- Desktop 负责规划、配置、管理、编排与同步；AE/PR 扩展负责宿主上下文与执行。
- 首发支持 Windows/macOS、AE/PR 2018—2026+、简体中文/英文、浅色/深色/跟随系统。
- 后续扩展日文、韩文。
- 所有新功能必须符合 Capability Registry、Action Schema、Safety、UI/UX、主题、多语言、无障碍和视觉自检规范。
