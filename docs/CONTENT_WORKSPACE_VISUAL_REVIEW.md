# 内容工作台视觉验收清单

本清单只检查视觉、布局和可读性。它不要求触发任何付费 Provider 请求，也不改变已保存的本地资产。

## 验收环境

- 分别检查 Dark 与 Light 主题。
- 优先检查 1440px 和 1280px 宽度；如时间允许，再检查 820px 以下的单列收缩。
- 刷新后确认仍停留在当前页面，再开始截图或检查。

## 内容生成

- 文案：左侧输入栏、中央空状态/文档结果、右侧大纲三者的阅读顺序清晰；未生成时中央不应出现一张占满页面的空白纸。
- 图片：提示词、设置与生成按钮均可读且不拥挤；预览为空时应显示居中的工作卡；右侧历史不应压缩主预览区。
- 视频：未绑定模型时，禁用按钮、原因与检查入口能被一眼区分；说明文字不应混杂成难读的中英文段落。
- 音乐：左侧为声音意图与参数，中央为音乐方向/结果，右侧为模型状态与历史；长提示词只在对应区域滚动，两个按钮始终可达。
- 配音：脚本、音色参数、台词清单与试听结果的层级清晰；生成按钮不会被脚本长度推离可视区域。
- 所有页：顶部模式切换可见，长 Provider / 模型名不会挤压或覆盖切换按钮；正文与标签无需放大浏览器即可读。

## 资源库

- 卡片首先表达资产类型和媒体，而不是显示完整提示词；标题最多两行且不会撑高单个卡片。
- 选中卡片有明确但克制的状态，卡片之间保留稳定间距。
- 详情栏的标题、预览、元数据和操作按钮顺序自然；长文本换行而不横向溢出。
- “恢复并再次生成”仍先显示确认窗；关闭或取消确认窗不应提交任何生成请求。

## 记录方式

如发现问题，请记录页面、主题、窗口宽度和截图，并标明是“阻断 / 需调整 / 通过”。优先反馈文字溢出、按钮不可达、滚动异常、视觉层级不清和主题对比不足的问题。
